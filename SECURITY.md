# Security policy

ET Verify is alpha software. It has not been security-certified and does not establish the security of a pull request.

Report potential vulnerabilities privately to [abram@empoweredtextlabs.com](mailto:abram@empoweredtextlabs.com). Include the affected ET Verify commit, the relevant workflow configuration, reproduction steps, and the observed impact. Do not include passwords, tokens, private keys, or other secrets in a report.

Please avoid public disclosure of exploitable issues until there has been reasonable time to coordinate a response. This project does not promise a response or remediation SLA and does not claim a formal security program.
